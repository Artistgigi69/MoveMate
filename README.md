# MoveMate 🚚

MoveMate is a full-stack web application that helps users manage utility transfers when moving to a new apartment.

## 🚀 Features

- User registration and login
- JWT authentication
- Protected routes
- Create / edit / delete transfers
- Manage electricity, gas, water services
- User profile
- Avatar upload
- Responsive UI

## 🛠 Tech Stack

Frontend:
- React
- Vite
- React Router
- CSS

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Multer

## 📂 Project Structure

movemate/
│
├── frontend/
│
└── backend/


## ⚙️ Installation

Clone repository:

git clone YOUR_LINK


Backend:

cd backend

npm install

npm start


Frontend:

cd frontend

npm install

npm run dev


## 🔐 Environment Variables

Create .env file:

MONGO_URI=
JWT_SECRET=
